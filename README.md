# 🍽️ College Mess Food Waste Analysis

## 🧠 Project Overview
This project focuses on analyzing food preparation and consumption patterns in a college mess to identify food wastage and associated financial losses. Using a realistic synthetic dataset, the analysis highlights meal-wise and item-wise wastage trends and proposes data-driven strategies to improve efficiency and reduce food waste.

All data used in this project is synthetically generated to simulate real-world scenarios and does not represent any actual institution.

---

## 🎯 Objectives
- Model daily food preparation and consumption in a college mess
- Identify meal-wise and item-wise food wastage patterns
- Quantify total food waste and estimate financial loss
- Visualize wastage trends for better decision-making
- Propose optimization strategies to reduce waste and improve cost efficiency

---

## 🛠️ Technologies Used
- Python  
- Pandas  
- NumPy  
- Matplotlib  

---

## 📁 Dataset Description
A realistic synthetic dataset was designed to represent daily food operations in a college mess.

| Feature | Description |
|------|-------------|
| Date | Day of food preparation |
| Meal Type | Breakfast, Lunch, Dinner |
| Food Item | Rice, Roti, Dal, Vegetables, Dessert, Snacks |
| Quantity Prepared (kg) | Total food prepared |
| Quantity Consumed (kg) | Food consumed by students |
| Quantity Wasted (kg) | Food left unused |
| Cost per kg (₹) | Cost of each food item |
| Waste Cost (₹) | Financial loss due to wastage |

---

## 📈 Analysis Performed
- Meal-wise aggregation of food waste
- Item-wise analysis to identify high-wastage food items
- Daily waste trend analysis
- Percentage waste calculation
- Estimation of financial loss due to food wastage

---

## 📊 Visualizations Included
- Bar charts showing food waste by meal type
- Bar charts showing food waste by food item
- Line plot illustrating daily food waste trends
- Pie chart representing contribution of each food item to total waste

---

## 🔍 Key Insights
- Certain meals consistently show higher food wastage
- Specific food items contribute disproportionately to total waste
- Over-preparation is a primary factor in increased food waste
- Food wastage results in significant avoidable financial loss

---

## 🧾 Conclusions
- Food waste can be significantly reduced through better demand prediction
- Portion size optimization is crucial for high-wastage meals
- Data-driven decision-making improves operational efficiency
- Continuous monitoring helps identify recurring inefficiencies

---

## 🚀 Recommendations
1. Optimize portion sizes for meals with consistently high wastage  
2. Adjust food preparation quantities for frequently wasted items  
3. Implement batch cooking and improved demand forecasting  
4. Introduce food waste tracking and awareness programs  
5. Explore donation options for excess safe-to-consume food  
6. Redesign menus to prioritize high-consumption, low-waste items
